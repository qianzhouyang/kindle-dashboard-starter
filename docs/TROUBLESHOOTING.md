# 故障排查

| 现象 | 检查方法 |
| --- | --- |
| Python / PIL / lunar_python 找不到 | 用 README 中 `.venv` 的 Python 安装并启动，不混用系统 Python |
| 地址打不开、端口占用 | 查看终端是否报错；可用 `--port 8003` 在自己的环境换端口；对应更新访问地址和设备 URL |
| 中文变方块 | 查看中文字体是否存在，按电脑教程指定自己的字体路径 |
| USB 未配置 | 核对当前数据目录里的 `device.json`；默认没有该文件，不会连接设备 |
| 手工 SSH 成功、控制台失败 | 相同私钥、用户、端口、known_hosts？带口令的私钥是否有可用 agent？控制台强制指纹检查和非交互模式 |
| SCP 报 SFTP 不支持 | 使用支持 `scp -O` 的 OpenSSH；确认 USBNetwork 的 SCP 支持 |
| Kindle 没出现 U 盘或网卡 | 两者是不同模式；按自己的 USBNetwork 文档切换与安装匹配驱动 |
| 横屏方向反了 | 全局参数切换 90°/270°；不要旋转已生成的设备 PNG 两次 |
| 时间不走 | 缓存模式是静态图片；自动模式也只按间隔换图，时钟来自电脑时间 |
| 天气仍是示例或地点不对 | 模式是否为 live？城市名称不会查坐标；填写并保存正确经纬度 |
| 同 Wi-Fi 能看图片但打不开控制台 | 预期行为；编辑必须在宿主机用 127.0.0.1 打开 |
| 自动模式拒绝运行 | 阅读日志中的 OTA/缓存/配置错误，不跳过保护检查 |
| 白屏、触摸或阅读未恢复 | 停止继续部署；请求 `--restore` 并保留日志，对照自己的原始备份和设备文档恢复 |

先收集：型号/固件、操作步骤、错误原文、`--status`、相关日志片段。
对外分享日志前移除自己的网络地址、路径、私有内容及设备标识。
不要上传整个运行目录或 SSH 文件来求助。
